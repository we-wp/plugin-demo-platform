# Demo interface system

## Direction

Bright editorial utility for WooCommerce merchants. Warm canvas, paper surfaces, ink typography, one cobalt action color, and mint used only for safe or ready states.

## Signature elements

- Text wordmark: `we-wp | plugins`.
- Real WooCommerce screenshots inside restrained browser frames.
- Asymmetric desktop and mobile proof in the hub hero.
- Dark demo workspace with a narrow module rail, matching the product's structured bundle model.
- Row-based plugin catalogue, not a generic card grid.

## Rules

- Geist is self-hosted.
- Body copy stays plain, short, and factual.
- One light site theme. The dark surface belongs only to the demo workspace.
- Buttons name an action. Unavailable runtime and coming-soon items never pretend to be links.
- Keyboard focus, loading, error, empty, disabled, and reduced-motion states are included.
