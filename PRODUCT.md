# Product brief

## Purpose

Let WooCommerce merchants try we-wp plugins before installing them.

## Audience

Store owners, developers, and agencies comparing WooCommerce extensions.

## Customer promise

Open a private demo in the browser. Use synthetic data. Reload to start clean. Nothing is sent to a real store, payment provider, or email address.

## Catalogue states

- **Advanced Bundles for WooCommerce:** screenshot tour and interactive private browser store available locally. The demo includes the product page, real plugin editor, cart, checkout, and clean reset.
- **Advanced Woo Invoices:** coming soon. No product, demo, source, or release link is shown.

## Public URL model

- Hub: `https://demo.we-wp.com/`
- Advanced Bundles: `https://demo.we-wp.com/plugins/advanced-bundles/`
- Future plugins: one stable path per plugin under `/plugins/`.

Paths keep one origin, one runtime cache, one security policy, and one health surface. Separate subdomains are reserved for future demos that require incompatible isolation or server-side services.
